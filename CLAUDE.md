This is for a simple github pages website, static, for my realtor to see what houses I'm looking at.

Houses should be sorted by a rating, where I rate them from 0 to 10 out of 10.

Ideally, I keep listings in a json file with basic information. If web-scraping is possible for Realtor.com or Zillow.com, that can be used to show information. If not, we will hard-code it into the json. Clicking on a "card" for a house will take the user to the listing url on the proper website.

Each card will have the listing address as the title, the score to the top left where it is first seen, a short personal description, number of beds, bath, whether it has a basement, garage, and a location score. Each metric will have one to three plusses for pros, and one to three minusses for cons.

Style should be minimalistic. Soft corners, low shading, good use of flex-box, system default fonts. Greyscale color theme.
